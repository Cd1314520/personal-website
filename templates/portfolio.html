Parametric PCB Thermal–Stress Simulation Pipeline

A headless PyMAPDL pipeline that procedurally generates printed circuit boards and solves coupled thermal–stress FEA end to end, built toward a large simulation dataset for machine learning. Research work with a University of Houston professor.

ANSYS / PyMAPDL Python FEA Automation ML Dataset

Pipeline

  • Procedurally places ICs and maze-routes copper traces (90° turns, shortest path, clearance constraints, no crossings), then meshes, solves, and exports results
  • Applies a coupled thermal load and mechanical load with fixed support, solving a ~113k-node model for von-Mises stress
  • Fully seeded and resumable: reproducible runs that log failures and skip already-finished boards
  • Runs on both a local machine and a UH lab workstation; guards the student-license core and node caps

Goal

Produce a large, consistent dataset of solved boards to train ML models that predict thermal–mechanical behavior directly from a layout, skipping the full solve.

TradingAgents — Automated Equity Analysis

A multi-model LLM system that researches equities and proposes trades, wired to a paper (simulated) brokerage account only — no real money. Built around risk gates that block premature and unsafe orders.

Python LLM Agents OpenRouter Risk Gating Paper Trading

Risk gates

  • Two-day sell confirmation — a Sell must repeat the next day before it liquidates, which caught three premature sells in production
  • Volatility gate — no new positions are opened on high-volatility (VIX) days
  • Truncated-analysis gate — a report cut off by the model's token limit is blocked from placing new buys, and the gate fails closed

Architecture

Multiple LLM providers with automatic failover and checkpoint resume, running unattended on a schedule with outbound alerts. Strictly a paper account — this is a research and engineering project, not investment advice, and no real funds are ever traded.

6-DOF Robotic Arm

A 6-degree-of-freedom robotic arm driven by an Arduino UNO and a PCA9685 16-channel PWM controller, teleoperated in real time from a PS5 DualSense controller.

Arduino Python PCA9685 / I²C pygame 3D Printing

Build

  • Six servos on a PCA9685 PWM driver (I²C, addr 0x40): 3× MG996R for base/shoulder/elbow, 3× MG90S for wrist and gripper
  • Dedicated external 5 V supply into the driver V+ rail, separate from the Arduino logic power
  • Per-channel soft limits enforced in both the Python control layer and the firmware

Control & debugging

  • PC-in-the-loop: pygame reads the DualSense, pyserial streams "<channel> <angle>" at 115200 baud, Arduino parses and drives the PWM
  • Real bring-up work: traced a dead I²C link to an A4/A5 miswiring, diagnosed servo stalls stripping gears, and caught a continuous-rotation servo mis-buy before swapping to angle-holding MG90S units

INA226 Energy Monitor Board

A custom PCB designed in KiCad around the INA226 power monitor: it measures voltage, current, and power on a load and reports the readings over I²C to a microcontroller.

KiCad PCB Design INA226 I²C Power Monitoring

Full schematic-to-layout design: INA226 current/power sense front end with a shunt across screw-terminal input and load, plus a 4-pin header breaking out 3.3 V, ground, and the I²C bus for a host microcontroller. Routed as a single-board layout in KiCad with a ground pour and edge cuts.

Personal AI Automation & Knowledge System

A personal automation system built on scheduled AI agents wired into my local Obsidian vault, handling email triage, a job and scholarship pipeline, and automatic knowledge capture.

Claude Code Obsidian Scheduled Agents Python Markdown

Scheduled Agents

  • Seven recurring tasks: a daily email digest, a morning brief, daily post drafts, a scheduled trading-agent check, a weekly job & scholarship pipeline, a weekly life summary, and a monthly portfolio sync
  • The weekly summary agent maintains a living context file that every other agent reads before acting, keeping outputs grounded in current project state
  • Structured CSV data backs the job, outreach, and scholarship pipelines

Knowledge Capture

  • A session-end hook captures every AI coding session into the vault, filed by date so long-running work lands on the right day
  • Structured Markdown templates and bidirectional links turn scattered notes into a queryable knowledge base
  • Agents read the curated vault for context-aware output instead of generic responses

Use Case

The system runs the repetitive parts of my week — triaging mail, drafting outreach, tracking applications, and logging what I build — while keeping a single source of truth that both I and the agents work from.
